**OVERVIEW**

Our Expense Tracker App is designed to help users manage their finances by tracking expenses and providing insightful reports. Whether you're managing personal finances or tracking business expenses, this app simplifies the process with its powerful features.

**FEATURES**.

1.Expense Logging: Easily log your expenses with categories and amounts.

2.Budgeting: Set budgets and listing transactions.

**USAGE**

There is a page that shows your main balance.
This page displays where you can set your budget, total balance, expenses and a list of transactions.

There is a buttion to add transaction where there is a label, here you can add the item you want to add, amount where you can state the price of your item and description where you can describe the item you are buying. eg weight.
